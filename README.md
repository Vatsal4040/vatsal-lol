# VATSAL.LOL

### A personal web platform for games, experiments, and interactive experiences.

**VATSAL.LOL** is an independently developed web platform built to bring together browser-based games, interactive projects, and digital experiments under one unified experience.

The platform focuses on lightweight technologies, individual game identities, responsive interfaces, and a consistent user experience.

**Live Website:** [https://vatsal.lol](https://vatsal.lol)

## ✨ Features

- **Browser-Based Games** — Play interactive games directly in the browser.
- **Individual Game Identity** — Each game maintains its own visual identity and experience.
- **Responsive Design** — Interfaces designed for desktop and mobile devices.
- **Progressive Web App** — PWA support for an enhanced browsing experience.
- **Offline Support** — Service worker and offline fallback functionality.
- **Lightweight Architecture** — Built around standard web technologies.
- **Continuous Development** — Regular improvements to functionality, performance, and accessibility.

## 📁 Repository Structure

The repository contains the platform's primary frontend files and supporting web configuration.

```text
VATSAL.LOL/
│
├── index.html          # Main entry point

│
```

*Individual game directories and additional assets are maintained within the repository.*

## 🎮 Platform Philosophy

VATSAL.LOL follows three core development principles:

**1. Individual Identity**

Every experience should retain its own personality rather than feeling like a generic collection of embedded games.

**2. Platform Separation**

Shared platform functionality and individual game functionality should remain clearly separated.

**3. Simplicity and Performance**

Prefer lightweight, maintainable solutions over unnecessary frameworks and dependencies.

## 🚀 Development

The platform uses standard web technologies.

1. Clone the repository.
2. Open the project directory.
3. Use a local development server to run the website.
4. Test functionality across desktop and mobile browsers.

```bash

cd VATSAL.LOL
```

## 🔐 Security & Ownership

VATSAL.LOL is an independently developed project.

Security and source protection are ongoing development priorities.

The project aims to:

- Keep credentials and private configuration out of public repositories.
- Protect sensitive server-side operations.
- Separate development resources from production assets.
- Review dependencies and deployment configuration.
- Apply appropriate security headers and access controls.

**Important:** Frontend code delivered to browsers is publicly inspectable. Minification and obfuscation do not constitute complete source-code protection.

Do not commit API keys, passwords, private tokens, or other confidential information.
